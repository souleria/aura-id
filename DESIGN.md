# Aura ID prototype

Working name only. Product direction comes from the supplied Aura ID brief: a neutral art gallery, editorial typography, and a collectible portable profile card. The expanded identity also captures working context and agent preferences.

ENERGY 2 / RHYTHM 3 / MOTION 1. Warm alabaster canvas and ink text keep the questionnaire readable. A restrained rust accent marks primary actions. A dark identity card is the focal object; its foil is confined to that object. Georgia provides the editorial serif without a remote font dependency. System sans keeps controls familiar. No external image assets or invented testimonials.

The repeated identity motif is a cropped set of concentric arcs on the passport. It represents the multiple layers of a profile and is decorative, not a biometric or measured personality score. Motion is limited to a short view transition and optional pointer tilt. Reduced-motion settings disable both.

One decision per view. Visual comparisons use the same content so unrelated attributes are not inferred. Defaults remain labelled as defaults until selected. Optional fields can remain unknown. Exports contain only selected sections. Boundary preferences never grant technical permissions.
